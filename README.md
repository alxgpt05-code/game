# Scooter Lab

**Играть:** https://alxgpt05-code.github.io/game/

**Исходники:** https://github.com/alxgpt05-code/game

Мобильный 3D-конструктор кастомного самоката. Статическое веб-приложение на JavaScript и Three.js, без серверной базы данных и без этапа сборки.

## Возможности

- Мастерская занимает весь доступный экран. Иконки категорий слева, 3D-модель по центру, вертикальная карусель справа.
- Выбор категории плавно приближает деталь внутри сборки. Для колёс камера наводится на переднее колесо.
- После автофокуса доступны свободное вращение, масштабирование и панорамирование. Замена варианта сохраняет ручной ракурс.
- 34 варианта деталей, включая колёса Mushroom, Neochrome и Root Honeycore по фотографиям.
- Сохранение сборок в localStorage этого браузера. Сохранённые сборки не синхронизируются между устройствами.
- Нижние показатели веса и стоимости скрыты в интерфейсе; расчёты остаются в коде.
- Кнопки над 3D-видом: ✓ сохранить, ▣ гараж, ⛶ полный экран. Полноэкранный режим зависит от поддержки браузера и запускается нажатием пользователя.

## Локальный запуск

Установленный Node.js, затем в папке проекта:

```sh
npm start
```

Открыть `http://127.0.0.1:4173`. Установка npm-пакетов не нужна. Three.js и шрифты загружаются через CDN, поэтому нужен интернет. Страницу следует открывать через HTTP, а не двойным щелчком по HTML.

Проверка синтаксиса:

```sh
npm run check
```

## GitHub Pages

1. Создать репозиторий и загрузить содержимое этого проекта в ветку `main`.
2. В **Settings → Pages → Build and deployment → Source** выбрать **GitHub Actions**.
3. Запустить **Actions → Publish Scooter Lab to GitHub Pages → Run workflow**, если первый запуск произошёл до настройки Pages.
4. Ссылка на опубликованную игру появится в выполненном задании и в **Settings → Pages**.

Workflow подготовлен по официальной документации: https://docs.github.com/en/pages/getting-started-with-github-pages/using-custom-workflows-with-github-pages

Публикация настроена для этого репозитория. Обновления ветки main автоматически запускают workflow.

## Структура

- `dist/index.html` — интерфейс.
- `dist/app.js` — каталог, выбор деталей, гараж.
- `dist/models.js` — геометрия и материалы 3D-деталей.
- `dist/geometry-config.js` — общая координата передней оси и преобразование геометрии вилки. Ось колеса находится впереди рулевой оси, а не позади неё.
- `dist/studio.js` — свет, камера, автофокус и ручное управление.
- `dist/style.css`, `dist/workshop.css` — адаптивная компоновка.
- `dist/assets/` — предоставленные фотографии-референсы и текстуры.
- `.github/workflows/pages.yml` — публикация в GitHub Pages.

## Точность моделей

Детали реконструированы по фотографиям и доступным размерам, это не заводские CAD-модели. Массы и цены с пометкой ≈ приблизительные. Параметры движения — игровые оценки, совместимость реальных товаров автоматически не проверяется.
